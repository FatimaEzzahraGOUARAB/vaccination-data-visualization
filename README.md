# Dashboard de suivi de la vaccination

Projet de visualisation de données de santé publique : extraction de données 
de vaccination via des requêtes MongoDB, puis analyse statistique et 
visualisation avec R et Python.

## Objectif
Transformer des données brutes de couverture vaccinale en visualisations 
claires et exploitables (évolution dans le temps, comparaisons par 
catégorie).

## Démarche
- Interrogation d'une base MongoDB pour extraire les données pertinentes
- Analyse et mise en forme statistique en R (Exo1_vaccination_dashbord.Rmd)
- Visualisation complémentaire en Python (visualisation_python.py)
- Publication des résultats sous forme de pages web (GitHub Pages)
